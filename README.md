✈️ Travelgram

Um perfil de viagem desenvolvido com HTML e CSS, inspirado em uma proposta de projeto do curso de formação Full Stack da Rocketseat.

📌 Sobre o projeto

O Travelgram é uma página de perfil de viagem que apresenta informações de um usuário e uma galeria de fotos de viagens.

Este projeto foi desenvolvido durante meus estudos no módulo de HTML e CSS da formação Full Stack da Rocketseat, com o objetivo de praticar e fixar os conceitos aprendidos ao longo do curso.

🎯 Objetivo

O principal objetivo deste projeto foi colocar em prática os conhecimentos adquiridos durante o aprendizado de:

Estruturação de páginas com HTML;
Estilização com CSS;
Organização de elementos;
Layout e posicionamento;
Flexbox;
Espaçamentos e alinhamentos;
Utilização de imagens;
Organização de arquivos e pastas.

🛠️ Tecnologias utilizadas

HTML5
CSS3
Git
GitHub
Live Server

✨ Funcionalidades

Perfil de usuário;
Informações do perfil;
Galeria de fotos de viagens;
Organização visual dos elementos;

📚 Aprendizados

Este projeto foi importante para praticar os fundamentos de HTML e CSS e compreender melhor como estruturar e estilizar uma página web.

Também foi uma oportunidade para começar a utilizar o Git e GitHub para versionamento e organização dos projetos desenvolvidos durante minha formação.

🎓 Formação

Projeto desenvolvido como parte dos estudos da Formação Full Stack da Rocketseat, durante o módulo de HTML e CSS.
